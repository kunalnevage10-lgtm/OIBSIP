## 🎯 Overview
This project implements supervised machine learning models to classify iris flowers into three distinct species:
- **Setosa**
- **Versicolor**
- **Virginica**

Classification is based on four morphological features:
1. `SepalLengthCm`
2. `SepalWidthCm`
3. `PetalLengthCm`
4. `PetalWidthCm`

---

## 🔬 Methodology & Workflow
1. **Exploratory Data Analysis (EDA)**:
   - Pair plots, distributions, and correlation heatmaps to observe feature separability (petal dimensions show clear linear distinction for Setosa).
2. **Preprocessing**:
   - Feature scaling and splitting into training (80%) and testing (20%) datasets.
3. **Model Training & Comparison**:
   - Logistic Regression
   - K-Nearest Neighbors (KNN)
   - Decision Tree Classifier
   - Random Forest Classifier
4. **Performance Evaluation**:
   - Evaluated using Accuracy Score, Confusion Matrix heatmaps, and Precision/Recall Classification Reports.
