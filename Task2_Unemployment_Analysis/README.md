## 🎯 Overview
An empirical analysis of the macroeconomic shock delivered by the **COVID-19 pandemic** on the Indian labor market throughout 2020. 

Using historical state-wise labor records (`Unemployment_Rate_upto_11_2020.csv`), this project investigates the unprecedented unemployment rate surges, workforce displacement, and regional variance during strict nationwide lockdown phases.

---

## 📊 Key Highlights & Visual Insights
- **Lockdown Shockwave**: Captured the dramatic unemployment spike during March, April, and May 2020 across both rural and urban sectors.
- **State-by-State Disparity**: Comparative bar charts and choropleths highlighting heavily affected states vs. resilient regions.
- **Labor Force Participation Rate (LFPR)**: Analyzed how total workforce participation contracted sharply as industries halted operations.
- **Interactive Visualizations**: Interactive Plotly charts with timeline sliders and detailed hover insights.

---

## 🚀 How to Run
Ensure `Unemployment_Rate_upto_11_2020.csv` is in the same directory, open `Unemployment_Analysis_Kunal.ipynb` in Jupyter Notebook, and run all cells.
